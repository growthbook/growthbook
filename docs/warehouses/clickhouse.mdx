## TLS and client certificate authentication (self-hosted only)

When self-hosting, you can point GrowthBook at PEM files on the GrowthBook server under **Advanced TLS Settings**. These settings require an `https://` URL.

- **CA Certificate Path**: CA bundle used to verify the ClickHouse server certificate. Set this alone to keep using password authentication with a private CA.
- **Client Certificate Path** and **Client Key Path**: certificate and key for [SSL certificate authentication](https://clickhouse.com/docs/concepts/features/security/ssl-user-auth). Both are required together, and a CA certificate path is also required. GrowthBook sends the username and the certificate, and does not send the password. The certificate file can be a PEM bundle with the leaf first, followed by its intermediates.
- **Client Certificate Chain Path** (optional): intermediate CA certificates that GrowthBook sends after the client certificate. Set this when the client certificate file contains only the leaf and ClickHouse trusts only the root CA. Otherwise the TLS handshake fails with `unknown ca`.

The ClickHouse user must be configured to accept the certificate's common name, for example:

```sql
CREATE USER growthbook IDENTIFIED WITH ssl_certificate CN 'growthbook.example.com';
```

GrowthBook reads the files every time it opens a connection, so certificates that are rotated on disk are picked up without a restart.
