GrowthBook does not query Keen IO directly. Track experiment exposure with the Keen SDK, export the event stream to a warehouse GrowthBook can query, then connect that warehouse as a data source.

## Exposure tracking

Record an experiment exposure event from the GrowthBook SDK `trackingCallback`.

```js
trackingCallback: (experiment, result) => {
  keenClient.recordEvent("experiment_viewed", {
    experiment_id: experiment.key,
    variation_id: result.key,
  });
};
```

## Export Keen IO to a warehouse

Keen IO can stream events to Amazon S3. From there, query the files with Athena, Presto, or Databricks. See [Keen IO's Amazon S3 streaming](https://keen.io/docs/streams/extended-functionality/amazon-s3/).

After the export is running, add Athena, Presto, or Databricks in GrowthBook and choose **Keen IO** as the event tracker. You will likely need to edit the assignment SQL to match your S3 table layout.
