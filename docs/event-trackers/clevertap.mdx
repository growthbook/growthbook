GrowthBook does not query CleverTap directly. Track experiment exposure in CleverTap, export those events to a warehouse, then connect the warehouse as a data source.

## Exposure tracking

Push an experiment exposure event from the GrowthBook SDK `trackingCallback`.

```js
trackingCallback: (experiment, result) => {
  clevertap.event.push("experiment_viewed", {
    experiment_id: experiment.key,
    variation_id: result.key,
  });
};
```

## Export CleverTap to a warehouse

CleverTap can export to BigQuery, Presto, Athena, and Databricks. See [CleverTap export](https://docs.clevertap.com/docs/export).

After the export is running, add that warehouse in GrowthBook and choose **CleverTap** as the event tracker. You may need to adjust the generated SQL to match your CleverTap export schema.
